# 도보 + 공식 버스 연결 PoC 설계 계약

2026-11-13. Opus에 관련 함수 시그니처·공식 API 사양·키 부재·평가판 범위를 제공해 읽기 전용 설계 검토를 받고 메인 구현자가 통합했다. 검토는 실제 공급자 실행 결과가 아니다.

## 변경 대상과 인터페이스

- `backend/scripts/verify_transit_poc.py`: 루트 환경 파일의 두 키를 사용하는 별도 CLI.
- `backend/contract_checks/test_transit_poc.py`: 외부 호출을 대체한 계약 검사.
- `.env.example`, 백엔드 문서·AI 기록의 링크만 보강한다.
- 기본 실행은 설정 확인만, `--live --departure RFC3339`일 때만 실제 요청한다. 기존 Google 도보 클라이언트는 그대로 재사용한다.

## 불변조건

1. 키가 없거나 `--live`가 없으면 외부 호출 0회.
2. Ekispert 3회·Google 최대 2회. 재시도·후보 쌍 순회·크롤러 폴백 없음.
3. 정류장은 provider 코드와 WGS84 좌표로 연결한다. 이름·근접 거리로 역을 합치지 않는다.
4. 출발 도보만큼 이동한 뒤의 시각으로 버스를 조회한다. 날짜 이월도 반영한다.
5. 실제 local bus와 시간표를 확인한 경로만 성공이다. 내부 도보는 중복 합산하지 않는다.
6. 키·원본 URL·응답·예외를 출력·저장하지 않는다. 리다이렉트를 따라가지 않는다.
7. 제품 API·추천·최적화·프론트·기존 크롤러는 변경하지 않는다.

## 수용·회귀 기준

사전 확인의 0호출, 객체/배열 응답, ID·좌표·수단·시간표·총시간, 반대 도보 방향, 날짜 이월, 쿼터 초과 전 차단을 검사한다. 실제 키 발급 전에는 지역 커버리지나 버스 연결 성공을 주장하지 않는다.

## 설계 검토에서 조정한 부분

버릴 수 있는 한 쌍의 진단 도구 범위를 유지해 좌표·반경을 바꾸는 CLI 인수, 파일 저장 인수, 별도 공급자 추상화는 추가하지 않았다. 대표점은 코드에 명시했다. 공급자 집계 시간과 시각 차이를 독립 비교하고, 모든 버스·철도 구간에 시간표 신뢰도를 요구한다. 실패하면 사유를 남기며 평균 시간으로 자동 전환하지 않는다.

평가판 지역 제한은 문서마다 적용 범위 설명이 달라 오사카 대표점을 사용하되 교토 모든 API가 불가능하다고 단정하지 않는다. 서버 호출의 도메인·IP 인증 조건은 실제 키 발급 시 확인해야 한다.
